# 2026-08-02 引擎架構升級：生態豐富化與圖形物理分離防線

## 今日進度與架構調整
今天為了拓展世界的方塊種類，並引進真實的自然生態景觀（橡樹林、礦脈、沙灘），我們對底層架構進行了一次決定性的防線升級。

### 1. `is_solid` 與 `is_opaque` 的剛性解耦
之前，我們的系統僅透過 `is_solid()` 來同時判定「物理碰撞」與「面剔除 (Face Culling)」。這在只有泥土和石頭時沒問題，但在引入了玻璃 (`Glass`) 與樹葉 (`OakLeaves`) 後便產生了嚴重的圖形漏洞：因為玻璃和樹葉是實心的（玩家可踩踏），但光學上半透明。若不拆分，緊貼在玻璃後方的泥土面會被錯誤地判定為「被遮擋」而遭到貪婪網格剔除，造成極為嚴重的透視漏光與破洞。
今天我將 `BlockType` 擴展出了 `is_opaque()` 函數：
* **`is_solid()`** 專司 **Swept AABB 碰撞**，確保玩家能在樹冠上行走、不穿過玻璃。
* **`is_opaque()`** 專司 **Greedy Meshing 剔除**，只有當鄰居方塊為「實心且完全不透明」時，才允許將當前面隱藏。
完美解決了玻璃與樹葉的剔除邏輯。

### 2. 跨區塊無縫樹木生成 (Cross-Chunk Boundary Trees)
地形生成器 (`generator.rs`) 實作了強大的二階段植樹管線。由於樹冠 (Leaves 3x3x3) 與樹幹 (Log) 有體積，若只在當前 `[0..32]` 區塊內進行生成，落在區塊邊界上的樹木將會被「一刀切平」，產生極不自然的半邊樹。
我們透過將樹木搜尋半徑向外擴張 2 格（`[-2..34]`），讓鄰近區塊的樹木也能順利將樹幹與枝葉「溢出」並寫入當前區塊的 `ChunkBuffer`。確保了跨界渲染完美無瑕。

### 3. 多重面貼圖與方塊擴展
正式將 `BlockType` 擴展為 11 種，並在 `texture_array.rs` 中補齊了：橡木、樹葉、沙子、礫石、煤礦、鐵礦與玻璃。
其中橡木原木 (`OakLog`) 實作了頂底面與側面的條件貼圖對應，還原了真實的原木紋理，並同時升級了 RLE 遊程編碼的反序列化以確保存檔相容性。

## 2026-08-02 (Update 2)：發光火把與動態晝夜交替系統

### 1. 雙軌光照引擎與 GPU 動態混合 (Dual Lighting Engine)
為了引入發光實體（如火把），我們徹底升級了 `ChunkLightBuffer`，將原本僅存天空光 (0~15) 的單一維度擴展為 **Sky Light + Block Light** 雙軌並行儲存。
為了解決頂點屬性用盡的問題，我們在 `greedy.rs` 中實施了【16-bit 頂點 XYZ 極限壓縮】：透過 `x + y*33 + z*1089` 將原本需佔用 18 bits 的空間壓縮至 16 bits。並將騰出的位元完美分配給 `block_light (4 bits)` 與 `sky_light (4 bits)`，塞入 `ATTRIBUTE_PACKED_DATA` 中一併送交 GPU。

### 2. 動態晝夜交替系統 (Day-Night Cycle)
遊戲內實裝了 `DayNightCycle` 資源，系統會根據真實時間流動更新時鐘 (0~24)，並透過正弦函數 (Sine Wave) 計算出 `sky_factor` (0.05~1.0) 傳遞給 Shader。
在 `voxel.wgsl` 中，我們讓 GPU 即時計算最終亮度 `max(sky_light * sky_factor, block_light)`。這使得夜間的火把能保持恆定高亮，而天色的晝夜變換【完全不需重新烘焙網格】，達成極致效能。

### 3. 流體雙軌光照支援
`generate_fluid_mesh` 系統同步迎來了 Block Light 支援。流體頂點在進行 AO 平滑採樣時，現在會同時對天空光與方塊光進行獨立的 8 鄰域環境光遮蔽混合，並利用與固體方塊同樣的 16-bit XYZ 壓縮技術，無縫整合雙軌光照至流體專屬材質管線中。

### 4. 植被渲染與除錯 UI 光照校正
修復了 GPU 片元著色器中草地與樹葉的自然綠色渲染 (Foliage Tint)，並同步校正了 F3 Debug 介面中針對光照的顯示算法。過去除錯文字直接顯示烘焙網格的原始 Sky Light (15)，現在會實時結合 `DayNightCycle` 的 `sky_factor`，顯示出真實運算後的物理表面光照亮度，解決了玩家在夜間誤認地表仍為滿亮度的疑惑。

### 5. 跨區塊植被光照阻斷與樹下陰影 (Foliage Shadow Casting)
修復了地形生成時，由於樹木是在 `max_surface_y` 計算之後透過 2D 雜湊動態生成，導致 `init_sunlight` 將天空光 15 級直通樹底的問題。我們在初始光照垂直掃描迴圈中引入了 `is_blocked` 剛性阻斷邏輯。一旦天空光在該垂直列遭遇樹葉 (`OakLeaves`) 或任何非空氣方塊，即刻強制中斷垂直直射特權，使樹下的空氣格初值為 0。隨後交由 BFS 泛洪演算法從周圍透光處水平擴散，完美還原了 Minecraft 中樹下光線微暗（從 15 衰減至 14、13）的自然陰影效果。

### 6. 深邃夜空、玻璃透視與快捷列火把 (Visuals & UX Refinements)
為了解決視覺層面的灰濛濛感，我們重構了 `update_fog_color` 的環境霧氣算法。將夜晚天空色從單調的壓暗蔚藍替換為真實的**深邃夜空藍 (Midnight Blue)**，配合動態內插讓晝夜交替的星空更加迷人。同時，將玻璃材質球 `VoxelMaterial` 的 `AlphaMode` 由硬質不透明改為 `Mask(0.5)`，並在片元著色器傳遞真實的貼圖 Alpha，配合微量淡藍 Tint，徹底告別玻璃灰塊。最後，將預設快捷列的第 9 格替換為 `Torch`，並接通了紋理索引，讓玩家得以親手驗證雙軌光照引擎的威力！

### 7. 火把獨立 3D 幾何與 UI 高亮校正 (Torch Mesh & UI Rendering)
修正了先前貪婪網格直接跳過非實心方塊導致火把無法顯示的問題。我們解耦了 `is_solid` 與網格生成的約束關係，並為 `BlockType::Torch` 實作了專屬的 3D 瘦長立體幾何 (`push_torch_quads` 6x6x10 像素比例)，使得火把不再是一個 1x1x1 的龐大方塊。
此外，針對物品欄 (UI) 渲染引擎 `build_single_voxel_mesh` 進行了雙軌光照升級，強制為預覽網格注入 15 級的 `block_light`。這解決了原本 UI 中 3D 方塊預覽圖在夜晚會因為 `sky_factor` 下降而變暗的視覺缺陷，並同時替 UI 中的火把套用了縮小的專屬幾何比例，大幅提升了玩家體驗與介面一致性。

### 8. 雙態火把放置與 GPU 程序化幾何變形 (GPU Morphing & Wall Torches)
徹底修復了傳遞浮點數頂點導致整數網格被截斷為 0 面積的火把隱形 Bug，以及後續導致的「發光斜線」與「黑色巨型方塊」顯示錯誤。
* **面剔除漏洞修復**：修正 `greedy.rs` 判斷相鄰面是否需要繪製時，錯誤地僅排除 `BlockType::Torch` 而漏掉牆面火把列舉（如 `TorchWallN`）的問題，將條件全面改為 `!b.is_torch()`，成功消滅了火把周圍爆出的巨大黑色實心幾何外框。
* **GPU 變形與 100% 精準 UV (Minecraft 原版還原)**：將火把幾何全權交由 Shader 處理。`greedy.rs` 推送火把方塊的原始基礎整數座標 `(bx, by, bz)` 作為頂點位置。在 `voxel.wgsl` 中偵測 `tex_id == 13u` 時，利用 `@builtin(vertex_index) % 4u` (0~3 角落) 與 `face_id`，在 GPU 端精確重建出 6x6x10 的瘦長立體木棍形狀。同時嚴格套用《Minecraft》官方 16x16 貼圖的 UV 範圍 (如 U: 0.4375~0.5625, V: 0.375~1.0)，讓火把像素與透明區域完美裁切。
* **牆面火把傾斜貼壁**：透過 Raycast 法線感知，新增了 `TorchWallN` 等牆面火把列舉，將牆面附著方向寫入 `flow_vector` 中，使得 GPU 能即時將牆面火把向後傾斜並精準貼緊牆壁！

### 9. 雙軌平滑光照貪婪合併 (Dual-Light Gradient Greedy Merging)
修補了平滑光照系統的一大漏洞。原先 `greedy.rs` 在進行面合併 (`can_merge`) 時，只檢查了天空光的 U/V 梯度，導致夜間（天空光全黑時），周圍不同火把光強度的網格被粗暴合併，破壞了光照漸層。更新後嚴格檢查了 `block_lights` 的四角平滑連貫性與對齊梯度，讓火把光能在周圍地形與牆面上，完美呈現如絲般順滑的平滑漸層 (Smooth Lighting)。

### 10. 火把六面完整性與互動修復 (Torch Integrity & Interaction Overhaul)
一次性修復了火把系統的 6 項致命缺陷，將火把從「殘缺的發光裝飾品」升級為完全可交互的功能性照明器具：
* **三角形繞行修正 (Winding Order Fix)**：`push_torch_quads` 在 `push_quad` 呼叫時強制統一使用 `rev: false`，消除了 GPU Backface Culling 吃掉 3 個反向面的隱形 Bug。火把六面全部完整可見。
* **Raycast 互動擴展**：修改了 `player/mod.rs` 中的視線 Raycast 判定條件，將 `block.is_solid()` 擴展為 `block.is_solid() || block.is_torch()`。火把（含牆面火把）現在可以被準星瞄準、顯示鋼絲邊框，並且支援左鍵挖除。
* **光照即時廣播 (Lighting Remesh Broadcast)**：修復了 `set_block_global` 末尾僅對單一區塊設置 `is_lighting_ready = true` 的漏洞。現在會對所有被 BFS 光照泛洪波及的區塊統一解鎖，消滅了放置火把後周圍區塊延遲亮起的 Re-mesh 阻塞問題。
* **牆面火把傾斜方向校正**：修正 `voxel.wgsl` 中 `flow_vector` 的偏移算式符號。底座偏移改為 `+flow`（貼向牆面），頂端傾斜改為 `-flow`（向房間內傾斜），徹底消滅火把「反向靠牆」的視覺錯誤。
* **快捷列 UI 火把修復**：在 `build_single_voxel_mesh` 中，火把統一傳送基礎原點 `[0,0,0]` 與 `rev: false`，讓 Shader 的 `vertex_index` 精準重建出正確比例的 3D 木棍模型，消除 UI 中的怪異變形。
