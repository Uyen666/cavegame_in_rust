# CaveGame 開發日誌：架構重構與 UI 地基建設

**記錄時間：** 2026-06-14
**當前進度：** 核心架構大重構、引入 GameState 狀態機

---

## 1. 核心架構大解耦
隨著專案規模成長，原先的模組劃分已經不敷使用。今天進行了一次「企業級」的架構重構，為未來的擴充（特別是主選單與多重世界）打下完美的基礎。

### 1.1 `src/world/` 的瘦身與分工
原本龐大的 `world/mod.rs` 承載了太多職責。我們將它拆分成：
- **`storage.rs`**：專職處理 `serde`, `bincode` 與非同步的硬碟 I/O。
- **`gen/mod.rs`**：地形生成演算法的專屬目錄。
  - **`flat.rs`**：純超平坦生成邏輯。
  - **`perlin.rs`**：柏林雜訊與自然山脈生成邏輯。
- **`mod.rs`**：現在只剩下純粹的生命週期管理 (`WorldPlugin`) 與區塊的生成/卸載排程。

### 1.2 物理系統獨立 (`src/phys/`)
原本屈居於 `utils` 底下的碰撞邏輯，現在正式被拔擢為一級模組 `phys`。
- 專門負責處理高階物理運算，例如從 `Aabb` 衍生出來的 `swept.rs` (Swept AABB 核心公式)。

## 2. 引入 GameState (狀態機) 與 UI 地基
沙盒遊戲不能只有「進去就開始挖」，我們需要主選單與設定介面。

### 2.1 狀態定義
在 `src/main.rs` 引入了 Bevy 強大的狀態系統：
```rust
pub enum GameState {
    MainMenu,
    WorldCreation,
    #[default] // 開發期暫時預設直接進遊戲方便測試
    InGame,
    Settings,
}
```

### 2.2 優雅的排程控制 (`.run_if`)
透過 Bevy 的 `.run_if(in_state(GameState::InGame))` 條件過濾器，我們現在可以一行程式碼關閉整個物理引擎、玩家操作、或是地形生成。這意味著當我們退回 `MainMenu` 時，背景的遊戲世界會完美地「凍結」，效能極高且沒有任何 Side Effect。

### 2.3 `src/ui/` 模組的誕生
新增了專門處理畫面的 UI 模組：
- **`hud.rs`**：接管了原本寫死在玩家腳本裡的十字準星，並利用 `OnEnter(GameState::InGame)` 與 `OnExit(GameState::InGame)` 做到「進入遊戲才畫出準星，退出遊戲自動清除」的完美生命週期管理。
- **預留擴充**：已經建立好 `main_menu.rs` 與 `settings.rs`，隨時可以開始刻畫精美的按鈕與選單介面。

## 3. 碰撞系統優化 (Minecraft 原版 EPSILON 防禦)
在這次更新中，我們進一步精煉了體素分軸移動系統，加入了防範浮點數誤差的關鍵幾何機制：
1. **安全外推邊距 (EPSILON = 0.001)**：在水平軸（X 軸與 Z 軸）發生碰撞彈回時，不只貼齊邊緣，還強迫玩家 AABB 額外遠離牆面 0.001 格的安全距離。
2. **根除虛假著地 (False Grounding)**：透過水平向的 0.001 微量隔離，確保在隨後執行的 Y 軸重力落地判定中，玩家的水平 AABB 絕對不會與牆壁邊角產生微觀重疊，徹底消除了斜向蹭牆時「瞬間被傳送/瞬移上方塊」的體素經典 Bug。
3. **精確地面對齊**：垂直 Y 軸向下彈回（站在地上）時不使用 EPSILON，令 `pos.y = ground_y`，保證腳跟完美貼齊地面並精確觸發 `is_grounded = true`。

## 4. Minecraft 材質包兼容與 Greedy Mesher 重構
為了讓引擎能直接無縫加載 Minecraft 標準的 ZIP 材質包，我們對渲染管線做了大翻新：
1. **動態解析度對齊**：加入硬體層面的 Texture Array 安全檢查。以 ZIP 中載入的第一張紋理為基準，自動將後續解析度不一的材質（例如把 `32x32` 或未裁切的材質）利用 `imageops::resize` 強制重採樣為統一的 `16x16`（或其他基準大小），防止 WebGPU 拋出陣列大小不匹配的 Panic。
2. **材質渲染管線修復**：修正了 Bevy 0.14 中 Bind Group 的索引衝突問題。確認了 Mesh Uniforms 佔用了 `@group(1)`，將我們的體素材質紋理綁定全面遷移至 `@group(2)`，徹底解決了 Wgpu 的 Validation Error。
3. **Greedy Mesher 數學完美化**：
   - 修正了 6 個面的頂點 CCW (逆時針) 繞向算法，所有軸向皆遵循 `rev = normal < 0` 統一規則，修復了 GPU Backface Culling 導致面消失的問題。
   - 修復了草地方塊 UV `V-Flip` 問題，側邊面 (North, South, East, West) 與上下面的貼圖映射皆已正確對齊。
   - 將材質 Layer 嵌入 `FaceInfo` 遮罩檢查中，確保不同朝向的相鄰方塊（例如草地頂部與側面）絕對不會被錯誤地合併，邊緣接縫與材質分配完美無瑕。
