# 2026-07-07 更新日記

## 1. 快捷列與手持方塊切換系統 (Hotbar & Block Selection)
為了讓建造體驗更為順暢且符合 Minecraft 傳統，我們實作了高度反饋的快捷列系統：
- **`Player` 結構體升級**：追加了 `hotbar: [BlockType; 9]` 陣列與 `selected_slot: usize` 當前選取格狀態，並於 `setup_player` 中預設注入了 Grass, Dirt, Stone 等多樣化方塊，並將其餘 6 格填滿 `Air`，徹底消除滑鼠滾動時連續碰到相同方塊而產生的「卡頓錯覺」。
- **雙軌切換輸入**：在 `player_input_capture` 中導入了兩種無延遲切換方式：
  - **數字鍵 1-9**：直接跳轉至指定欄位 (0-8)。
  - **滾輪能量累加器 (MouseWheel)**：利用 `ev.y` 動態切換，捨棄粗暴的向零截斷，實作了 `scroll_accumulator` 高精度能量池與 `0.7` 剛性閾值。不僅保留了極致絲滑的微動慣性，更實裝了防溢位的剛性模除 `+ 8 % 9` 與 `+ 1 % 9`，確保滾輪怎麼滑都不會觸發 Out of Bounds 陣列越界。
- **動態方塊放置**：徹底閹割了 `player_interaction` 中寫死的右鍵放置 `BlockType::Stone` 硬編碼，改為動態讀取 `player.hotbar[player.selected_slot]`。玩家現在可以自由選擇手上的方塊類型進行建造。

## 2. 第一幀地形傳送安全鎖 (Instant Surface Spawning)
修復了玩家首次登入時，因為世界尚未完全非同步生成，導致出生在幽閉洞穴內或是只能從高空「慢慢掉落」的問題。
我們在 `Player` 中導入了 `has_spawned` 狀態鎖，將玩家初始高度設於 `250.0` 並剛性凍結重力與移動。系統會在背景靜默輪詢玩家腳底的 3D 區塊；一旦加載完畢，便會發射垂直射線掃描出最高固體方塊，並在單影格內將玩家「零延遲傳送」到地表上。確保你進遊戲的瞬間，必定雙腳貼地且抬頭能看見遼闊的天空。

## 3. VS Code 專屬整合終端環境與 Tasks 設置 (DevEnv Enhancements)
為了解決重啟後 VS Code 整合終端機遺失環境變數，導致 `cargo` 指令失效的問題，我們在專案根目錄建立了 `.vscode` 隱藏設定：
- **`settings.json`**：使用 `terminal.integrated.env.windows` 強制將 `C:\Users\林尚楷\.cargo\bin` 注入終端機的 `PATH`。
- **`tasks.json`**：新增了一鍵執行 `Cargo Run` 的專屬 Build Task，現在開發者只需按下 `Ctrl+Shift+B` 即可無縫編譯並啟動遊戲，徹底擺脫反覆輸入指令的繁瑣流程。

## 4. F3 除錯介面：手持方塊即時顯示 (F3 Holding UI)
我們強化了 F3 Debug UI 系統，為了配合快捷列，我們在渲染迴圈中動態查詢了 `player.hotbar[player.selected_slot]`。現在只要按下 F3，你不僅能看到座標、FPS、目標方塊，還能明確看到 `Holding: XXXXX` 的即時回饋，保證你能掌控當前即將放置什麼方塊。
