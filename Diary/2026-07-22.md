# 2026-07-22 更新日記

## 1. 目標方塊鋼絲邊框 (Target Block Wireframe)
為了提供與 Minecraft 同等級的視覺反饋，我們在玩家視角系統中實裝了高精度的「目標方塊高亮邊框」：
- **3D 體素射線步進 (Raycast Stepping)**：以相機為起點，沿著 `forward` 向量以 `0.05` 為步長向前推進 5.0 公尺，精準捕捉第一個碰觸到的固體方塊。
- **微擴張防閃爍幾何 (Anti Z-fighting)**：利用 `Gizmos` 在該方塊座標上繪製邊框時，特別將立方體邊界縮放設為 `1.002` 倍。這微小的擴張能夠完美包裹住方塊網格，徹底杜絕了鋼絲與方塊兩面緊貼時，深度測試運算衝突造成的 (Z-fighting) 閃爍問題。
- **旁觀者權限分離**：這項邊框顯示邏輯同樣受到 `is_spectator` 狀態的嚴格防護。當玩家切換至上帝飛行模式時，鋼絲邊框會自動隱藏，確保上帝視角的純淨巡檢不被干擾。

## 2. 2D 快捷列 UI 介面 (Hotbar HUD)
我們正式實作了位於螢幕底部的 2D 快捷列，提供與經典遊戲同級的視覺反饋：
- **UI 佈局與元件**：在 `hud.rs` 中使用 Bevy 內建的 Flexbox UI 生成了 9 個 `48x48` 像素的半透明方格，整齊排列於螢幕底部中央。
- **Changed<Player> 效能防護**：利用 ECS 的變更追蹤 (Change Detection) 篩選器 `Changed<Player>`，確保 `update_hotbar_ui` 只會在玩家實體狀態（如滾輪切換、按鍵點擊）發生實質變更時，才重新計算與更新 UI。
- **高動態視覺回饋**：當前的 `selected_slot` 會自動切換為高對比的「亮黃色選中邊框」，其餘則保持低調的暗灰色。同時每個方塊會利用 `Text` 節點即時顯示其對應的 `BlockType` 類型（如 `Air`, `Stone`, `Grass`），讓你隨時掌控即將放置的方塊。

## 3. 快捷列視覺整形與細節優化 (Hotbar Visual Polish)
我們對原本稍顯陽春的快捷列進行了一次深度的視覺大升級：
- **消除視覺空洞**：在每個方格內部左上角新增了 `Val::Px(10.0)` 大小的微型灰色鍵位數字 (`1` 到 `9`)，大幅提升操作指引。
- **UI 紋理採樣預覽 (Texture Sampling)**：將原本的純色塊升級為真正的 `ImageBundle`，並在系統啟動時透過 `HotbarTextures` 資源載入 `assets/textures/grass.png` 與 `stone.png` 等原生材質貼圖。在切換快捷列時，程式會將正宗的 2D 貼圖映射到 UI 上；若該方塊（如 Dirt）暫無圖片檔案，則會優雅降級（Graceful Degradation），自動退回顯示高品質向量色塊（如泥土棕）。
- **精準的 UiImage 著色引擎**：修復了 `Handle::default()` 預設白圖遮蔽的 Bug，全面改用 Bevy 的 `UiImage.color` 來進行濾鏡染色（Tint）與透明度控制，確保空氣 (Air) 是完美的透明留白，而泥土 (Dirt) 也能精準渲染出純淨的對應色塊。
- **Air 留白防護**：當方塊為 `Air` 時，將文字與顏色強制清空，徹底絕殺了之前畫面上顯示一排 "Air" 的突兀感，保持空間留白。
- **選中框動態加粗**：被選中的方格邊框厚度會動態由 `1.0` 膨脹至 `3.0`，並採用極高對比度的鮮明金黃色 (`1.0, 0.84, 0.0`)，未選中則降為暗灰，提供強烈的視覺引導與立體感。
